# Homebrew Tap for gcpx

This is the official Homebrew tap for [gcpx](https://github.com/andres-pcg/gcpx) - GCP Context Switcher.

## Installation

```bash
brew install andres-pcg/tap/gcpx
```

Or add the tap first:

```bash
brew tap andres-pcg/tap
brew install gcpx
```

## Updating

```bash
brew update
brew upgrade gcpx
```

## About gcpx

A fast, secure CLI tool for managing multiple Google Cloud Platform accounts with seamless switching of both gcloud configurations and ADC credentials.

See the [main repository](https://github.com/andres-pcg/gcpx) for full documentation.
